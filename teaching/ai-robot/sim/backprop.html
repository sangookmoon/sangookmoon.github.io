파이썬 · Octave 실행하는 법

상자 위의 「파이썬 · Octave」 단추로 언어를 고른다. 한 번 고르면 모든 상자가 같은 언어로 바뀐다.

파이썬은 무료 프로그래밍 언어이고, numpy 는 숫자 배열 계산을 빠르게 해 주는 파이썬 도구다. 이 페이지의 파이썬 코드는 파이썬 3 과 numpy 만 있으면 돌아간다.

설치 없이 해 보기 : 웹 브라우저로 Google Colab 에 들어가 「새 노트」를 만든다. 코드 셀에 붙여 넣고 ▶ 단추를 누른다. numpy 는 이미 들어 있다. 구글 계정이 필요하다.

내 컴퓨터에 설치 : python.org 에서 파이썬 3 을 내려받아 설치한다. 터미널에서 pip install numpy 를 한 번 실행한다. 코드를 bp.py 같은 파일로 저장하고 python bp.py 로 실행한다. 윈도우에서 python 이 안 되면 py bp.py 를 쓴다.

노트북으로 : pip install jupyterlab 뒤 jupyter lab 을 실행하면 브라우저에 노트북이 열린다. 셀 하나에 한 상자씩 붙여 넣는다.

GNU Octave 는 무료 공개 소프트웨어로, 숫자 · 행렬 계산을 짧은 코드로 할 수 있다. 문법이 MATLAB 과 거의 같아서 이 페이지의 Octave 코드는 MATLAB 에서도 돌아간다.

Octave 를 설치 없이 : 웹 브라우저로 무료 웹 서비스 Octave Online 에 들어가 코드를 붙여 넣고 Enter.

Octave 설치 : 공식 다운로드는 octave.org/download. 윈도우는 「Windows-64 (recommended)」의 installer.exe 를 받아 실행한다. 맥은 Homebrew 가 있으면 터미널에서 brew install octave, 우분투는 sudo apt install octave.

Octave 로 실행 : Octave 를 열고 상자의 「코드 복사」를 누른 뒤 명령 창에 붙여 넣고 Enter. 저장해 두려면 편집기에 붙여 넣어 .m 파일로 저장하고 실행한다.

이어서 실행 : 「1쪽 코드에 이어서」라고 적힌 상자는 같은 노트북에서 1쪽 상자를 먼저 실행한 뒤 실행한다. 파일로 할 때는 앞 상자 코드 아래에 붙여 쓴다.
