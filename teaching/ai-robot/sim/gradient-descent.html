식 정리 (x = 크기 ÷ 1000, y = 가격 ÷ 1000, 집 4채)

예측
ŷ = w × x
ŷ (와이 햇) = 모자(^) 쓴 y = 모델이 예측한 가격 (직선 위의 값). 모자 없는 y 는 실제 가격
오차
e = ŷ − y
예측이 실제보다 크면 +, 작으면 −
손실
(절댓값)
J = 1mmΣi=1| ŷi − yi |
= |e₁| + |e₂| + |e₃| + |e₄|4 (집 4채로 풀어 쓴 것)
부호만 떼고 그대로 더한다. 이것을 평균 절대 오차라고 한다. 제곱하지 않으므로 w 의 1차식 조각들. ÷ 2 는 제곱 식에서만 쓰는 약속이라 여기는 ÷ m
손실
J = 12mmΣi=1(ŷi − yi)²
= e₁² + e₂² + e₃² + e₄²2 × 4 (집 4채로 풀어 쓴 것)
m : 집 수(4) · Σ : i = 1 부터 m 까지 모두 더하기 · ŷi − yi : i 번째 집의 오차 ei
제곱 → + 와 − 가 상쇄되지 않고, 큰 오차일수록 훨씬 크게. ÷ 2 는 5쪽에서 J 의 기울기를 구할 때 제곱의 2 와 지워지게 붙이는 약속
기울기
J 의 기울기 = 1mmΣi=1(ŷi − yi) xi
= e₁x₁ + e₂x₂ + e₃x₃ + e₄x₄4 (집 4채로 풀어 쓴 것)
음수 → w 를 키운다, 양수 → w 를 줄인다
업데이트
w ← w − 학습률 × J 의 기울기
학습률 : J 의 기울기에 곱하는 작은 수. 한 스텝에 w 가 움직이는 양은 학습률 × J 의 기울기라서, 학습률이 그대로여도 기울기가 작아지면 스텝도 작아진다
예측
ŷ = w × x + b
w : 1분에 오르는 온도, b : 시간이 0 일 때의 온도(처음 물 온도). 교재에 따라 hθ(x) = θ₀ + θ₁x 로 쓰는 꼴 (b 가 θ₀, w 가 θ₁)
오차
e = ŷ − y
예측이 실제보다 크면 +, 작으면 −
손실
J(w, b) = 12mmΣi=1(ŷi − yi)²
식은 같다. 다만 w 와 b 두 숫자에 따라 달라지므로 그릇이 두 방향으로 펼쳐진다 → 3차원 그림이나 위에서 본 등고선으로 그린다
기울기
J 의 w 쪽 기울기 = 1mmΣi=1(ŷi − yi) xi
J 의 b 쪽 기울기 = 1mmΣi=1(ŷi − yi)
J 의 w 쪽 기울기 : b 는 그대로 두고 w 만 조금 바꿀 때 J 가 기운 정도(직선의 기울기 w 와 다르다). b 쪽도 마찬가지. b 쪽은 x 를 곱하지 않는다. b 에는 늘 1 이 곱해진다고 보면 된다. Octave 로 X = [ones(m,1), x] 를 만들 때 1 열의 1 이 그것이다
업데이트
w ← w − 학습률 × (J 의 w 쪽 기울기)
b ← b − 학습률 × (J 의 b 쪽 기울기)
두 숫자를 같은 스텝에서 함께 업데이트한다

Octave 란? 설치하고 코드 실행하는 법

GNU Octave 는 무료 공개 소프트웨어로, 숫자 · 벡터 · 행렬 계산과 그래프 그리기를 짧은 코드로 할 수 있다. 문법이 MATLAB 과 거의 같아서 이 페이지의 코드는 MATLAB 에서도 그대로 돌아간다.

설치 없이 해 보기 : 웹 브라우저로 Octave Online(무료 웹 서비스)에 들어가 코드를 붙여 넣고 Enter.

설치하기 (공식 다운로드 : octave.org/download)

  • 윈도우 : 「Windows-64 (recommended)」의 installer.exe(약 540 MB)를 받아 실행한다. 2026년 11월 기준 최신판은 11.3.0.
  • 맥 : Homebrew 가 있으면 터미널에서 brew install octave
  • 리눅스 (우분투) : sudo apt install octave

코드 실행하기 : Octave 를 연다(윈도우는 시작 메뉴의 GUI 쪽). 실습 상자의 「코드 복사」를 누르고, 명령 창(Command Window)에 붙여 넣은 뒤 Enter. 그래프는 새 창으로 뜬다. 저장해 두려면 편집기(Editor)에 붙여 넣어 .m 파일로 저장하고 실행(F5)한다.

읽는 법 : % 뒤는 설명(주석)이라 실행되지 않는다. 줄 끝에 ; 가 있으면 결과를 화면에 보이지 않고, 없으면 보인다. .* · .^ 는 칸끼리 곱하기 · 제곱이다.
